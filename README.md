# 三国杀·二人完整卡牌版

Godot 4.6 正式版、纯 GDScript 4.x。玩家控制主公 Player1，基础 AI 控制反贼 Player2。对局开始前可从 25 名标准版武将中选将，双方身份、武将资料与性别数据互相独立。

## 运行

1. 使用 Godot 4.6 打开本目录的 `project.godot`。
2. 按 F6/F5 运行主场景，从序章地图进入第一战，在选将面板选择武将后点击“开始对局”。
3. 无需第三方插件、字体或图片素材。

## 操作

- 选将：点击任意武将，AI 会从剩余武将中选择；也可载入“曹操 VS 吕布”默认配置。
- 重新开始：游戏结束后可沿用双方武将重新开始，或点击“重新选将”返回选将面板。
- 主动牌：点击手牌后点击角色目标，或直接把牌拖到角色区。
- 【无懈可击】：锦囊即将生效时，按提示选择使用或放弃；允许继续反无懈。
- 【决斗】/AOE/借刀：按提示打出【杀】、【闪】或放弃响应；丈八蛇矛可用两张手牌响应。
- 【八卦阵】：需要【闪】时可点击“发动【八卦阵】”进行判定。
- 【丈八蛇矛】：出牌阶段或需要【杀】时可点击“两牌当【杀】”。
- 【铁索连环】：点击后可选择自己、对手、双方或重铸。
- 【五谷丰登】：亮出的牌会暂时显示在手牌区，点击选择。
- 【火攻】：目标点击一张手牌展示；来源点击同花色牌弃置，也可放弃。
- 延时锦囊、四个装备区和连环状态会显示在双方角色状态栏。
- 弃牌阶段按提示点击手牌，弃到当前体力上限。
- 主动技/视为技：点击技能按钮后选择实体手牌或装备代价；需要目标时再点击角色区。
- 【制衡】：可连续点击手牌和装备按钮进行多选，确认前不支付代价，可随时取消。
- 触发技：出现询问时点击“发动”或“不发动”；锁定技满足条件时自动生效。
- 【无双】：响应栏显示需要的牌数和当前 `已响应/需要` 数量。
- 【铁骑】：马超使用【杀】后提示“发动判定/不发动”；红判时目标不能使用【闪】或【八卦阵】。
- 【国色】：大乔先选一张方块手牌或方块装备，再选择目标，进入完整【乐不思蜀】流程。
- 【结姻】【青囊】：先选代价手牌、再点角色目标，确认前可取消，不支付任何代价。
- 【急救】：华佗在自己的回合外濒死（或救援对方）时点击【急救】按钮，再点一张红色手牌或红色装备。
- 【流离】【离间】：严格双人局没有合法目标，按钮自动禁用并说明“双人局无合法目标”。

## 武将与技能

- 曹操（魏，4）：【奸雄】受到伤害后可获得仍在处理区的来源实体牌。
- 张辽（魏，4）：【突袭】摸牌阶段可放弃正常摸牌，随机获得对手一张手牌。
- 许褚（魏，4）：【裸衣】少摸一张，本回合使用【杀】或【决斗】造成的伤害 +1。
- 关羽（蜀，4）：【武圣】将红色手牌或红色装备当【杀】使用或打出。
- 张飞（蜀，4）：【咆哮】锁定技，出牌阶段使用【杀】无次数限制。
- 赵云（蜀，4）：【龙胆】将【杀】与【闪】互相转化使用或打出。
- 甘宁（吴，4）：【奇袭】将黑色手牌或黑色装备当【过河拆桥】使用。
- 孙权（吴，4）：【制衡】每回合限一次，弃置至少一张牌并摸等量牌。
- 吕布（群，4）：【无双】锁定技，【杀】需要两张【闪】；决斗对手每轮需要两张【杀】。

技能按两个互相独立的维度描述：

- 发动方式：主动技、触发技、视为技、规则修正。
- 标签与次数：锁定技、无限次、每回合限次。

玩家与 AI 共用同一套技能合法性、代价、目标和结算入口。

## 卡牌与规则

基础牌：

- 【杀】【闪】【桃】【酒】

普通及群体锦囊：

- 【过河拆桥】【顺手牵羊】【无中生有】【决斗】【借刀杀人】
- 【五谷丰登】【桃园结义】【无懈可击】
- 【南蛮入侵】【万箭齐发】【铁索连环】【火攻】

延时锦囊：

- 【乐不思蜀】：判定不为红桃，跳过出牌阶段。
- 【兵粮寸断】：判定不为梅花，跳过摸牌阶段。
- 【闪电】：黑桃 2~9 造成 3 点雷电伤害，否则传递。

规则系统还包括：

- 每个目标效果独立进入无懈响应链；奇数层抵消、偶数层恢复生效。
- 决斗双方轮流打出【杀】。
- 火焰/雷电伤害触发铁索连环传播，传播时相关角色重置。
- 延时锦囊进入判定区，并可在判定效果生效前被【无懈可击】。
- 距离按 `max(1, 1 + 目标+1马 - 来源-1马)` 计算；【杀】比较攻击范围，【顺手牵羊】和【借刀杀人】限制距离1。
- 四个独立装备区支持同类替换、失去装备与弃牌堆结算。
- 武器：【诸葛连弩】【青釭剑】【寒冰剑】【青龙偃月刀】【丈八蛇矛】【贯石斧】【方天画戟】【朱雀羽扇】【麒麟弓】。
- 防具：【八卦阵】【藤甲】【白银狮子】；坐骑：+1马、-1马。
- 所有规则步骤同时输出到 Godot 控制台和界面对局日志。

`GameManager` 是唯一规则入口。UI 和 AI 只发送请求，不能直接修改领域状态；技能只声明钩子、参数修正或结构化结算请求。实体牌先进入处理区，整条效果结束后才弃置，因【奸雄】被取得的牌不会重复进入弃牌堆。伤害、濒死和胜负继续复用同一结算链。

## 第二批标准武将（18 将版本）

战斗选将现已扩展为 18 名武将。新增：司马懿（反馈、鬼才）、夏侯惇（刚烈）、郭嘉（天妒、遗计）、甄姬（倾国、洛神）、刘备（仁德）、诸葛亮（观星、空城）、吕蒙（克己）、黄盖（苦肉）、周瑜（英姿、反间）。第一批 9 名武将、基础牌、15 种锦囊和完整装备系统保持不变。

选将面板使用纵向滚动区域，1280×720 下可浏览全部武将和完整技能说明。对局角色状态栏保持紧凑，悬停可查看技能类型、次数范围与完整说明。

新增交互：

- 【鬼才】：判定窗口显示原因与当前判定牌；点击一张手牌改判，或点击“放弃改判”。
- 【遗计】：临时牌只对郭嘉本人展示。逐张点选，再选择“交给主公/反贼”，全部指定后确认；取消调整时两张牌归郭嘉，保证不丢牌。
- 【观星】：临时牌只对诸葛亮本人展示。按期望的置顶顺序点选牌，未选择的牌按顺序置底；也可保持原顺序。
- 【仁德】：点击技能后多选手牌，再确认交给对手；取消确认不会移动牌。
- 【倾国】：响应【闪】时先点【倾国】，再点一张黑色手牌；装备区牌不能作为代价。
- 【反间】：目标先从四种花色中选择，之后才随机获得并公开一张牌。
- 【苦肉】：按钮进入结算后立即锁定；失去体力导致濒死时先完成自救，成功后才摸两张。

## 第三批标准武将（25 将版本）

战斗选将现扩展为 25 名武将。第三批新增：马超（马术、铁骑）、黄月英（集智、奇才）、大乔（国色、流离）、陆逊（谦逊、连营）、孙尚香（结姻、枭姬）、华佗（急救、青囊）、貂蝉（离间、闭月）。

新增通用规则能力：

- 武将性别：`GeneralDefinition.gender`（MALE/FEMALE）；女性为甄姬、黄月英、大乔、孙尚香、貂蝉。【结姻】【离间】只读取性别字段。
- 统一牌移动事件 `CardMoveContext`：使用、打出、弃置、获得、交给、偷取、拆除、装备替换和技能代价全部走 `GameManager._move_cards` 原子入口；一次移动多张牌先整体完成，再触发移动后事件。
- 失去最后手牌：一次原子移动令手牌从有到无，只产生一次“失去所有手牌”事件，供【连营】触发；已经空手时无牌移动不触发。
- 失去装备：每张离开装备区的实体牌产生一次“失去装备”事件，【枭姬】【白银狮子】进入 TriggerQueue 串行结算。
- 他人救援：`DYING_RESCUE` 扩展为当前 `rescue_actor` 逐张救援；濒死者先自救，不足 1 再询问另一方；【酒】只能自救，【桃】与华佗【急救】可救他人。
- 目标转移：`SlashTargetContext` 记录【杀】来源/原目标/当前目标等；【流离】先验证新目标合法再转移，不重新支付【杀】。


成功输出：`THIRD_BATCH_SKILL_SMOKE_TEST: PASS (7 remaining standard generals; 25 total)`。
