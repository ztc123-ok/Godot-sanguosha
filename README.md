# 三国杀·二人基础版

一个可直接用 Godot 4.6 正式版打开运行的纯 GDScript 4.x 工程。玩家控制主公 Player1，反贼 Player2 由基础 AI 控制。

## 运行

1. 使用 Godot 4.6 打开本目录的 `project.godot`。
2. 点击编辑器右上角“运行项目”（F6/F5 均可，主场景已配置）。
3. 无需安装插件、字体或图片素材。

## 操作

- 点击【杀】，再点击上方反贼区域；也可以把【杀】直接拖到反贼区域。
- 【桃】和【酒】可点击使用，也可拖到自己的角色区域。
- 被 AI 的【杀】指定时，选择“使用【闪】”或“不使用闪”。
- 濒死时，使用【桃】或【酒】；若体力低于 0，需连续救援到 1。
- 点击“结束出牌阶段”后，若手牌超上限，按提示点击手牌弃置。

## 已实现规则边界

- 两名角色均为 4 点体力，主公先手，反贼为 AI。
- 完整阶段：开始 → 判定 → 摸 2 → 出牌 → 弃牌 → 结束。
- 每回合限使用一张【杀】。
- 【闪】仅用于响应【杀】。
- 【桃】主动回复或濒死自救，不超过体力上限。
- 【酒】强化本回合下一张【杀】；濒死时视为【桃】自救。
- 酒杀即使被闪避，酒的强化也已消耗。
- 手牌上限等于当前体力；牌堆耗尽后洗混弃牌堆。
- 本基础版仅包含【杀】【闪】【桃】【酒】，不含武将技能、装备、锦囊、距离和判定牌。

## 结构

```text
scenes/Main.tscn
scripts/
├── Main.gd
├── GameManager.gd
├── Player.gd
├── UIManager.gd
├── cards/
│   ├── Card.gd
│   ├── SlashCard.gd
│   ├── DodgeCard.gd
│   ├── PeachCard.gd
│   ├── WineCard.gd
│   └── CardFactory.gd
└── ui/
    ├── CardView.gd
    └── PlayerDropZone.gd
```

`GameManager` 是唯一规则入口，使用阶段与响应状态机保证“出牌 → 闪响应 → 伤害 → 濒死自救 → 返回出牌阶段”的顺序。`Player` 只保存角色数据；`UIManager` 只做显示和输入转发；卡牌子类只声明自身可用条件。
