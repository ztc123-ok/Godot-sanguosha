# 《三国杀》双人版第三批武将技能 Agent 扩展提示词

> 前置基线：先完整阅读第一批和第二批武将技能提示词。  
> 本文件不是从零生成提示词，只用于在前两批共 18 名武将已经实现并通过测试后，增量补齐标准包剩余 7 名武将。

## 扩展范围

- 第一批 9 名：曹操、张辽、许褚、关羽、张飞、赵云、甘宁、孙权、吕布。
- 第二批 9 名：司马懿、夏侯惇、郭嘉、甄姬、刘备、诸葛亮、吕蒙、黄盖、周瑜。
- 第三批 7 名：马超、黄月英、大乔、陆逊、孙尚香、华佗、貂蝉。
- 完成后共 25 名标准版武将。
- 使用标准版（旧标）技能，不混入界限突破、国战或 1V1 专属技能。
- 当前项目保持纯双人局。标准技能在双人局没有足够合法目标时必须判定为不可发动，不擅自改造成其他效果。
- 本批不实现主公技、限定技、觉醒技、使命技、转换技，也不为这些未使用类型创建占位枚举或空流程。

一、必须保持的架构边界

1. 兼容 Godot 4.6 stable；禁止 Godot 3.x 语法、废弃 API、第三方插件和伪代码。
2. Main 只绑定 GameManager 与 UIManager。
3. GameManager 仍是阶段、目标、距离、判定、牌移动、技能触发、伤害、濒死、救援、胜负和 AI 的唯一规则入口。
4. BattlePlayer 只保存武将、技能、体力、手牌、装备、判定区及明确标记，不直接推进流程。
5. Skill 脚本只声明发动条件、规则修正和结构化结算请求，不直接修改体力、手牌、装备、牌堆或 FlowState。
6. UIManager 只订阅状态并调用 request/can_*；玩家和 AI 共用相同合法性、代价、目标和结算入口。
7. 继续使用既有 `ActivationMode.ACTIVE/TRIGGERED/VIEW_AS/MODIFIER`、`SkillTag.LOCKED`、`UsageScope.UNLIMITED/PER_TURN`，不增加本批没有使用的技能类型。
8. 继续使用处理区、实体牌/虚拟牌、SkillUseContext、DamageContext、DrawContext、JudgementContext、TriggerQueue、continuation、skill_owner/skill_actor 和 generation。
9. 每个技能的询问、发动、放弃、代价、判定、牌移动、回复、救援和返回状态均同时写入控制台与界面对局日志。

二、本批需要补充的通用能力

只在现有框架不足时增加以下能力，禁止把技能按武将名硬编码进 GameManager 的巨大 if/match：

1. 武将性别
   - GeneralDefinition 新增 `gender`，只实现本标准包需要的 `MALE` 和 `FEMALE`。
   - 女性：甄姬、黄月英、大乔、孙尚香、貂蝉；其余当前 25 名武将均为男性。
   - 性别是规则数据，不得通过武将中文名、头像或 UI 文本推断。

2. CardMoveContext/统一牌移动事件
   - 至少记录 cards、owner/source、from_zone、to_zone、reason、skill/card source、移动前后手牌数和 continuation。
   - 使用、打出、弃置、获得、交给、偷取、拆除、装备替换、装备作为技能代价都必须走统一牌移动入口。
   - 一次移动多张牌时先原子完成整次移动，再触发“移动后”技能，不能逐张修改中途状态导致重复触发。

3. 失去最后手牌
   - 当一次原子牌移动令角色手牌数从大于 0 变为 0 时，产生一次“失去所有手牌”事件。
   - 同一次移动失去多张且最终为 0，只触发一次【连营】；已经空手时发生无牌移动不能触发。
   - 连营摸到牌后，未来再次失去最后手牌可以再次触发。

4. 失去装备
   - 每张从装备区离开的实体牌都产生一次统一“失去装备牌”事件。
   - 正常替换、过河拆桥、顺手牵羊、寒冰剑/麒麟弓效果及装备作为技能代价都必须触发同一入口。
   - 白银狮子、枭姬等离场效果进入 TriggerQueue，按明确顺序逐个结算，不能由 UI 或 Player.equip 直接补效果。

5. SlashTargetContext/目标转移
   - 记录【杀】的来源、当前目标、原目标、伤害、属性、实体牌、有效牌类型、护甲忽略和返回 continuation。
   - 目标转移必须先验证新目标合法，再取消原目标并建立新目标；不得重新支付【杀】、重复计出杀次数或生成第二张实体牌。

6. DyingRescueContext/他人救援
   - 扩展现有只允许自救的 DYING_RESCUE，使另一方可以对濒死角色使用【桃】或合法的视为【桃】。
   - 濒死者先获得自救机会；若仍未回复至 1，再询问另一方。需要多次回复时循环请求，直到体力至少为 1，或所有合法救援者明确放弃且无可用救援牌。
   - 【酒】仍只能由濒死角色本人自救，不能对另一方使用。
   - 每次只提交一张实体/虚拟【桃】，结算后重新检查体力；不得一次按钮调用直接把体力设为 1。
   - 救援操作者可能不是 current_player，授权必须读取 rescue_actor，不能用当前回合所有者拦截。

按需要新增或扩展 FlowState，至少清楚表达：

- SKILL_SELECT_CARDS：国色、流离、结姻、青囊、离间的代价牌；
- SKILL_SELECT_TARGET：结姻、青囊及技能目标；
- SLASH_TRANSFER：流离目标转移；
- DYING_RESCUE：扩展为当前 rescue_actor 的逐张救援；
- 现有 SKILL_CONFIRM、SKILL_RESOLVING、JUDGEMENT_REPLACE 等继续复用。

每个状态必须保存实际操作者、合法代价、合法目标、确认/取消/无目标分支和原 continuation。无合法目标的技能不得先支付代价。

三、第三批 7 名标准版武将

每个技能使用独立脚本，在 GeneralFactory 和 SkillFactory 注册，并显示技能名、类型、完整说明和当前可用状态。

1. 马超，蜀，4 体力，男性

   马术（锁定技，`MODIFIER + LOCKED + UNLIMITED`）：
   - 马超计算到对手的距离时额外 -1。
   - 与现有 -1 马叠加，并在全部加减完成后统一执行 `max(1, distance)`。
   - 只修改“马超作为来源到目标的距离”，不修改对手到马超的距离，不直接增加武器攻击范围。

   铁骑（触发技，`TRIGGERED + UNLIMITED`）：
   - 马超使用【杀】指定对手后、进入闪响应前，可以判定。
   - 最终判定牌为红色时，对手不能使用或打出【闪】响应此次【杀】，直接继续未闪避分支。
   - 最终判定牌为黑色或马超放弃发动时，按原规则进入【闪】响应。
   - 对手不能响应闪时也不能发动八卦阵获得视为闪；青釭剑、藤甲、无双等其他规则仍按各自入口处理。
   - 实体【杀】、武圣/龙胆形成的虚拟【杀】都能触发；借刀要求马超打出的【杀】也按实际使用者规则处理。

   AI：目标可能有闪/八卦阵时优先发动；判断结果和鬼才改判均读取最终 JudgementContext。

2. 黄月英，蜀，3 体力，女性

   集智（触发技，`TRIGGERED + UNLIMITED`）：
   - 每当黄月英实际使用一张非延时锦囊牌时，可以摸一张牌。
   - 在牌已合法提交并进入处理区后触发，即使该锦囊之后被无懈抵消也已满足发动条件。
   - 不因使用乐不思蜀、兵粮寸断或闪电触发；不因“打出”一张牌但未形成锦囊使用事件而触发。
   - 每次使用事件至多触发一次，不能因为群体锦囊逐目标结算而重复摸牌。

   奇才（锁定技，`MODIFIER + LOCKED + UNLIMITED`）：
   - 黄月英使用锦囊牌无距离限制。
   - 【顺手牵羊】【借刀杀人】等原本要求距离为 1 的锦囊对黄月英跳过距离限制，但仍检查目标区域有牌、目标有武器、同名延时锦囊不能重复等其他条件。
   - 不修改【杀】距离、武器范围、对手到黄月英的距离或非距离类目标限制。

   AI：合法锦囊使用后默认发动集智；选择锦囊目标时复用奇才修正后的 can_* 判断。

3. 大乔，吴，3 体力，女性

   国色（视为技，`VIEW_AS + UNLIMITED`）：
   - 出牌阶段可以将一张方块手牌或方块装备牌当【乐不思蜀】使用。
   - 目标、判定区同名牌限制、无懈链、延时锦囊放置和后续判定完全复用现有【乐不思蜀】流程。
   - 装备牌作为代价时走统一失去装备入口；真实代价牌成为延时锦囊的实体牌，不得另造一张复制品。

   流离（触发技，`TRIGGERED + UNLIMITED`）：
   - 大乔成为【杀】的目标时，可以弃置一张手牌或装备牌，将此【杀】转移给大乔攻击范围内、且为该【杀】来源合法目标的另一名角色。
   - 必须先存在合法转移目标，才能询问发动和支付代价；成功后取消大乔目标并让新目标进入完整“成为杀的目标”及响应流程。
   - 当前严格双人局只有【杀】来源和大乔两名角色，来源不能成为自己使用【杀】的目标，因此【流离】通常没有合法目标：按钮应隐藏/禁用，AI 不尝试，不能弃牌换成“取消杀”。
   - 保留完整技能脚本和合法性检查，但不得为双人局擅自改成摸牌、免伤或直接抵消【杀】。

4. 陆逊，吴，3 体力，男性

   谦逊（锁定技，`MODIFIER + LOCKED + UNLIMITED`）：
   - 陆逊不是【顺手牵羊】和【乐不思蜀】的合法目标。
   - 在选择目标的规则层直接拒绝，覆盖实体牌、国色形成的虚拟【乐不思蜀】及其他复用这两种有效牌类型的入口。
   - 不能先成为目标再依赖无懈或 UI 取消；不影响过河拆桥、兵粮寸断和其他锦囊。

   连营（触发技，`TRIGGERED + UNLIMITED`）：
   - 每当一次原子牌移动令陆逊失去所有手牌后，可以摸一张牌。
   - 使用/打出最后一张牌、被获得/弃置最后一张、将最后一张交给他人或作为技能代价都能触发。
   - 同一次移动失去多张且最终空手只触发一次；连营摸牌后将来再次失去最后手牌可再次发动。
   - 触发发生在牌移动完成后，并在原使用、响应或技能 continuation 继续前结算，不能破坏处理区实体牌的后续去向。

   AI：连营默认发动。

5. 孙尚香，吴，3 体力，女性

   结姻（主动技，`ACTIVE + PER_TURN`，`max_uses = 1`）：
   - 出牌阶段可以弃置两张手牌并选择已受伤的男性对手，令孙尚香和该对手各回复 1 点体力。
   - 对手必须为男性且 `hp < max_hp`；孙尚香本人可以满体力。
   - 只能使用两张手牌作为代价，不能选择装备；确认前可取消，确认后原子弃置两张，再依次通过统一回复入口结算双方回复。
   - 对手为女性、未受伤或孙尚香不足两张手牌时不可发动，不得先弃牌。

   枭姬（触发技，`TRIGGERED + UNLIMITED`）：
   - 每当孙尚香失去装备区里的一张牌后，可以摸两张牌。
   - 装备替换、被拆/被顺、寒冰剑/麒麟弓移除及装备作为技能代价都通过统一牌移动事件触发。
   - 一次事件失去一张装备触发一次；若通用入口一次移走多张装备，则按实际失去的每张装备分别排入触发队列。
   - 枭姬结算不能阻止已发生的装备移动，也不能让同一装备重复触发。

   AI：只有在自身回复收益足够且代价合理时使用结姻；枭姬默认发动。

6. 华佗，群，3 体力，男性

   急救（视为技，`VIEW_AS + UNLIMITED`）：
   - 华佗在自己的回合外，可以将一张红色手牌或红色装备牌当【桃】使用。
   - 可以用于华佗在对手回合中濒死时自救，也可以在对手濒死时救援对手；自己的回合内不能发动急救。
   - 装备作为代价时走统一失去装备入口；每张红牌只形成一张有效【桃】，不能一次直接把濒死角色回复到 1。
   - 复用扩展后的 DyingRescueContext、桃回复、濒死退出和原 continuation；不能另写华佗专用的直接加血流程。

   青囊（主动技，`ACTIVE + PER_TURN`，`max_uses = 1`）：
   - 出牌阶段可以弃置一张手牌，令一名已受伤角色回复 1 点体力。
   - 双人局可选择受伤的华佗自己或受伤的对手；目标必须 `hp < max_hp`。
   - 只能弃手牌，不能弃装备；确认前可取消，确认后支付代价并走统一回复入口。

   AI：优先用青囊治疗自己，通常不治疗敌方；对敌方濒死默认不发动急救，但必须明确放弃并让救援流程继续。华佗自己可被急救挽救时应正确发动。

7. 貂蝉，群，3 体力，女性

   离间（主动技，`ACTIVE + PER_TURN`，`max_uses = 1`）：
   - 出牌阶段可以弃置一张手牌或装备牌并选择两名男性角色，指定其中一名视为对另一名使用【决斗】。
   - 两名角色必须不同，且被指定为【决斗】来源者能够合法对另一名使用【决斗】；离间生成的决斗复用既有决斗响应、无双、伤害、濒死和技能触发流程。
   - 装备作为代价时走统一失去装备入口；没有完整合法目标组合时不得支付代价。
   - 当前严格双人局中貂蝉为女性，场上最多只有一名男性对手，无法选择两名男性，因此【离间】不可发动：按钮隐藏/禁用，AI 不尝试，不得改写成让对手直接与貂蝉决斗。
   - 仍需保留完整技能元数据、脚本和 can_* 合法性检查，日志/说明明确当前无合法目标。

   闭月（触发技，`TRIGGERED + UNLIMITED`）：
   - 貂蝉的结束阶段开始时，可以摸一张牌。
   - 在切换当前玩家之前询问并结算；发动/放弃后只能继续一次原结束阶段 continuation，不能额外获得回合。

   AI：闭月默认发动；离间在当前双人局不进入尝试循环。

四、关键规则交互

1. 马术和坐骑按同一距离修正管线叠加；全部修正后距离最低为 1。
2. 铁骑使用统一判定管线，允许鬼才改判、天妒获得最终判定牌；红色结果禁止所有来源的有效【闪】，包括倾国和八卦阵。
3. 集智按“一次锦囊使用事件”触发，不按目标数、无懈层数或效果分支重复触发。
4. 国色只改变有效牌类型，实体方块牌的区域移动、花色和最终去向保持可追踪。
5. 谦逊、奇才、空城等合法性修正必须在 GameManager 的 can_target/can_use 层组合，不以 UI 是否显示目标代替规则。
6. 连营在统一牌移动完成后进入 TriggerQueue；使用最后一张牌时，先结算连营再恢复该牌原本的使用/响应 continuation。
7. 枭姬只监听装备区离开事件，与白银狮子等其他离场技能使用触发队列串行结算，同一实体装备不能重复触发。
8. 他人使用【桃】和急救必须复用统一救援队列；濒死者恢复到 1 后立即退出剩余救援请求，所有旧按钮/AI 回调失效。
9. 【流离】【离间】在当前双人局无合法目标是正常规则结果，不能为了“测试技能有效”而改变标准技能含义。

五、选将与 UI

1. 在现有选将列表加入第三批 7 名武将，完成后共有 25 名；AI 从玩家未选择的武将中选择，测试可按 general_id 确定性指定。
2. 25 名武将卡片和长技能说明必须可滚动，不能撑出 1280×720。
3. 对局角色区显示性别、势力、体力、技能名、技能类型及本回合已用状态。
4. 国色、结姻、青囊需要清晰的技能按钮、选牌、目标、确认和取消流程；不得与普通点牌出牌混淆。
5. 铁骑显示“发动判定/不发动”；连营、枭姬、闭月显示“发动/不发动”。锁定技不显示可放弃按钮。
6. DYING_RESCUE 明确显示濒死角色、当前救援操作者、可使用桃/酒/急救及放弃按钮；只有实际 rescue_actor 可以操作。
7. 大乔/貂蝉当前没有合法目标时，【流离】【离间】不可点击，并在技能说明或提示中说明“双人局无合法目标”，不能弹出无法完成的选择层。
